# Talap v2 — как применить

Файлы кладутся поверх репозитория по тем же путям. Ничего из существующего кода
не удаляется, кроме двух файлов, которые заменяются целиком.

```
app/globals.css              ← ЗАМЕНИТЬ
app/layout.tsx               ← ЗАМЕНИТЬ
app/auth/callback/route.ts   ← новый
lib/storage.ts               ← ЗАМЕНИТЬ (API прежняя + replaceStore/touchToday/onStoreChange)
lib/i18n/dictionary.ts       ← новый
lib/i18n/index.ts            ← новый
lib/supabase/client.ts       ← новый
lib/supabase/server.ts       ← новый
lib/supabase/types.ts        ← новый
lib/supabase/sync.ts         ← новый
components/i18n/*            ← новые
components/auth/*            ← новые
middleware.ts                ← новый (в корне)
supabase/schema.sql          ← новый
.env.example                 ← ЗАМЕНИТЬ
```

## 1. Зависимости

```bash
npm i @supabase/supabase-js @supabase/ssr
```

Больше ничего ставить не нужно. `Bricolage Grotesque` и прочие дисплейные
шрифты сознательно не добавлены — почти ни один из них не несёт казахские
глифы `ә ғ қ ң ө ұ ү һ і`, а 21 из 26 пилотов в казахской параллели. Inter несёт,
поэтому вся система на нём, и в `layout.tsx` добавлены сабсеты `latin-ext` и
`cyrillic-ext` — без них казахские буквы подменялись системным шрифтом прямо
посреди слова.

## 2. Supabase

1. Создать проект на supabase.com, регион — ближайший (`eu-central-1` даёт из
   Казахстана лучшую задержку, чем US).
2. SQL Editor → New query → вставить `supabase/schema.sql` целиком → Run.
3. Authentication → Providers → включить **Google** и **Email** (в Email
   выключить «Confirm password», нам нужен только magic link).
4. Authentication → URL Configuration:
   - Site URL: `https://talap.online`
   - Redirect URLs: `https://talap.online/auth/callback`,
     `http://localhost:3000/auth/callback`
5. Project Settings → API → скопировать `Project URL` и `anon public` в
   `.env.local` и в переменные окружения Vercel.

`service_role` ключ в проект не попадает вообще. Все таблицы закрыты RLS по
`auth.uid()`, поэтому анонимного ключа достаточно и утечка его не открывает
чужие строки.

## 3. Проверить, что гостевой режим не сломался

Запусти **без** переменных Supabase:

```bash
npm run dev
```

Сайт должен работать ровно как раньше: работы открываются, прогресс пишется в
localStorage, кнопок входа нигде нет. Это не побочный эффект, а требование —
`isSupabaseConfigured()` скрывает весь UI аккаунтов, если ключей нет.

# Что осталось поменять в существующих компонентах

Патч даёт фундамент — дизайн-токены, языки, бэкенд. Компоненты пока ссылаются
на классы v1 (`.brutal`, `.press`, `.t-display` со старыми размерами, `.pill`).
Они не сломаются: старые имена либо остались, либо не встречаются в новом CSS,
но выглядеть будут наполовину по-старому. Порядок, в котором их стоит
переписывать, задан данными пилота, а не удобством.

## Приоритет 1 — контент 11 класса

**Это важнее всего остального в этом документе.**

В `data/exams/` лежит 11 работ: десять за 10 класс, одна за 12. Для 11 класса —
ноль. При этом 18 из 26 пилотов учатся в 11 классе, а `curriculum.ts:233`
возвращает для 11 класса пустой список профильных предметов.

Из десяти человек, кто ушёл с сайта быстрее чем за 5 минут, шестеро —
одиннадцатиклассники. Из восьми, кто просидел больше 30 минут, семеро — тоже
11 класс, то есть те, кто добрался до работ за 10 класс и начал решать.
Распределение бимодальное не из-за дизайна, а из-за того, что часть людей
открыла пустую полку.

Нужны работы по English (90 баллов) и Я2 (100 баллов). До этого — временная
заглушка: `library.empty.*` в словаре уже написана и предлагает открыть работу
другого класса вместо пустого экрана.

## Приоритет 2 — сравнение ответов

Три пилота получили «правильный ответ засчитало как неправильный». Пилот №12
объясняет причину: не принимаются эквивалентные формы записи — `2x-6` против
`-6+2x`.

В `lib/grading.ts` сравнение сейчас строковое. Нужна нормализация перед
сравнением: убрать пробелы, привести десятичную запятую к точке, отсортировать
слагаемые в сумме, сократить дробь, принять `0.5` = `1/2` = `½`. Плюс поле
`acceptedAnswers: string[]` в типе вопроса для случаев, которые нормализацией
не берутся.

Он же просит несколько полей ввода на многочастных заданиях — примитив
`.answer-row` в новом CSS под это уже есть.

## Приоритет 3 — ИИ не отвечает

Самая частая жалоба: 6 упоминаний из 26. Две отдельные проблемы.

Настоящая задержка — в `lib/server/providers.ts` нет таймаута и нет ретрая.
Нужен `AbortController` на ~20 секунд, один повтор, и падение в offline-ветку
вместо зависания.

Воспринимаемая задержка — панель не подаёт признаков жизни. В новом CSS есть
`.shimmer`, `.skeleton-line` и `.dots`, а в словаре — `tutor.thinking`,
`tutor.slow` (показывать после 8 секунд) и `tutor.failed`. Это чинится в
`components/exam/TutorDrawer.tsx` и `components/AskTalap.tsx`.

## Приоритет 4 — мобильная вёрстка

С телефона заходили 14 из 26, и их средняя оценка дизайна 2.79 против 3.60 у
тех, кто был с компьютера. Пять отдельных жалоб «криво выглядело на телефоне».

Конкретно:
- `components/Hero3D.tsx` и `HeroCanvas.tsx` — three.js сцена на телефоне это
  и есть «сайт долго загружался» (3 упоминания). Отдавать её только при
  `min-width: 768px`, на телефоне — статичная SVG-шкала.
- `.phone-tilt` из v1 удалён: повёрнутый на 17° макет телефона внутри телефона
  нечитаем.
- `components/exam/ExamWorkspace.tsx` — переходы между вопросами перенести в
  `.thumbbar` (липкая нижняя панель, уже в CSS), сейчас они наверху страницы.
- Дисплейный кегль упал со 108px до 64px максимум, `line-height` тела с 1.17
  до 1.55. Пилот №14: «нужно больше пространства, читать и разбираться почти
  никто не будет».

## Приоритет 5 — язык работ

Пилот №7: работы за 10 класс показаны на английском, хотя оригинал сдавался на
казахском, «на некоторых задачах в условии вообще непонятно по математике».

Инфраструктура готова: `Localised<T>` и `pickContent()` в `lib/i18n/index.ts`.
Тип вопроса в `lib/exam-types.ts` меняется так, чтобы `stem`, `markScheme` и
`topic` принимали либо строку, либо `{ kk, ru, en }`. Порядок отката —
запрошенный язык → русский → английский, потому что казахоязычному ученику без
казахской формулировки русская ближе английской.

Переводить всё сразу не нужно. Начать с двух работ Grade 10 Mathematics Paper 1 —
именно их решали 9 пилотов, больше любых других.

# Что изменилось в дизайне и почему

Жёлтый остался основным цветом и встречается **чаще**, чем в v1: каждая главная
кнопка, каждое активное состояние, заливка прогресса, текущая оценка, блок
бренда. Изменилась площадь.

Шесть пилотов написали про жёлтый: «ядерный», «бьёт в глаза», «режет глаза»,
«била по глазам». Пилот №26 добавил решающее: «если бы не фон — можно
использовать на постоянной основе». Претензия была не к цвету, а к тому, что
`#fff824` заливал целые экраны.

Поэтому в v2 жёлтый — это шкала:

| Токен | Значение | Где применяется |
|---|---|---|
| `--color-y-50` | `#fffceb` | большие поверхности, секции |
| `--color-y-100` | `#fff6c2` | карточки, чипы |
| `--color-y-400` | `#ffdd2d` | **бренд** — кнопки, активное, маркер |
| `--color-y-500` | `#f5c800` | нажатое состояние, границы |
| `--color-y-700` | `#8a6a00` | жёлтый, проходящий по контрасту как текст |

Правило: `--color-y-400` в полную силу не занимает больше ~30% экрана. Крупные
плоскости берут `y-50`/`y-100` — они читаются жёлтыми, но без глейра.

Вторая половина проблемы — холодный фон `#f3f3f3`. Холодный серый рядом с
ядерным жёлтым максимизирует конфликт по цветности. Канва стала тёплой
бумажной `#fbfaf6`, в одном тоновом семействе с жёлтым.

Убраны жёсткие смещённые тени `5px 5px 0` и бордюры 3px — на 380 пикселях они
читались как шум. Осталась видимая грань 1px и мягкая тень: система по-прежнему
«напечатанная», а не глянцевая.

Двое пилотов просили **больше** анимации, а не меньше — `.reveal`, `.stagger`
и `.mark-sweep` в CSS под это.
